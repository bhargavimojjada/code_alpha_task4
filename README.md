# Basic Chatbot Website

A small rule-based chatbot built with HTML, CSS, and JavaScript. It responds to
`hello`, `how are you`, and `bye`, and displays a fallback reply for other
messages.

## Run it

Open `index.html` in a modern web browser. No installation or server is required.

## Files

- `index.html` — page structure and chat controls
- `styles.css` — responsive styling
- `script.js` — chatbot replies, input handling, and message display
